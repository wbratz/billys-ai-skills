# Billy's AI Skills

Reusable AI agent skills, plugins, and marketplace scaffolds.

## Layout

- `claude/`: Claude Code skills, agents, plugins, registry, templates, and Claude-specific guidance.
- `openai/`: OpenAI Codex skills, plugins, custom subagent templates, marketplace metadata, and `AGENTS.md`.
- `ai_docs/`: Research and implementation notes for AI agents.

## OpenAI/Codex marketplace

The Codex marketplace root is `openai/`.

```bash
codex plugin marketplace add ./openai
```

Codex project instructions live in:

```text
openai/AGENTS.md
```

## Claude Code marketplace

Claude-specific guidance lives in:

```text
claude/CLAUDE.md
```
