# Codex Custom Agents

Use this folder for shared documentation and published custom agent definitions.

Codex active project-scoped custom agents are TOML files under:

```text
.codex/agents/{agent-name}.toml
```

Keep inactive reusable starter files in `../templates/agent/` until the user asks to activate them.

Custom agents should be narrow. Define a clear job, description, and developer instructions.
