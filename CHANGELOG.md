# Changelog

All notable repository releases are documented here.

## 0.1.0 - 2026-07-28

The first public release of Billy's AI Skills.

### Included

- `rlm` for planned long-context analysis in Claude Code
- `rlm-auto` for conservative automatic routing and local evaluation
- `rlm-codex` for dry-run planning and bounded recursive analysis in Codex
- a fictional product-launch corpus and reproducible terminal demonstration
- cross-marketplace validation, automated tests, dependency auditing, and
  security guidance

### Known boundaries

- The plugins are experimental and require review before sensitive use.
- Live RLM runs require provider credentials or a compatible local model.
- Local execution should be limited to trusted context.
