# Atlas Launch Packet

This fictional packet exists to demonstrate cross-document RLM analysis without
using private, customer, or employer information.

The documents intentionally disagree in small but meaningful ways. A useful
answer must connect the product requirement, architecture, decision history,
and launch review instead of summarizing each file independently.

Try this question:

> What changed between the PRD and implementation, why did it change, and what
> launch risks remain?

The recorded example answer lives in
[`../../demo/expected-synthesis.md`](../../demo/expected-synthesis.md), outside
the source corpus.
